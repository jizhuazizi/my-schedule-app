# 个人日程管理软件 · 第一版网页原型

这是按照最终需求文档制作的 Windows 网页端第一版原型。

## 打开方式

直接双击 `index.html` 即可打开。若需要测试浏览器语音能力，建议用本地服务器打开，例如在 `app` 文件夹中运行：

```powershell
python -m http.server 5173
```

然后访问 `http://localhost:5173`。

## 当前已实现

- 浅色界面和左侧菜单
- 我的事项、今天、已安排、已完成、设置
- 新增、编辑、完成、取消完成、删除
- 可选截止日期和时间
- 24 小时制、5 分钟粒度输入
- 西雅图 / 北京双时区显示
- 默认关闭的提醒设置
- 同一事项支持多个提醒（例如提前 1 小时和提前 5 分钟）
- 每天、每周、每月重复设置
- 当前页面内标题和副标题搜索
- 浏览器本地保存，刷新后数据保留
- 第一版验收记录：按钮与选项检查记录.md
